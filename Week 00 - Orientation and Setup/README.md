# Week 0 — Orientation and Setup

**Before the system diagram starts.** This week has no box on it — it's the
one live online session that gets everyone to the same starting line before
Week 1 begins.

---

## By the end of this session you can

1. Say what CST1510 is, in one sentence, and why it's the same for all
   three lanes for the first seven weeks
2. Explain what CW1 and CW2 are, and where their deadlines actually live
3. Say what a normal week looks like: workshop, then lab, same shape every
   time
4. Run a Python file and open a Jupyter notebook on your own machine
5. Read `verify_setup.py`'s output and know whether you're ready for
   Week 1
